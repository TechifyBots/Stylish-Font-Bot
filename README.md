## 🌸 Overview

**Stylish Font Bot** is a creative Telegram bot that transforms **normal text into stylish and decorative fonts** in seconds. With a wide collection of text styles and an easy-to-use interface, it helps you make your messages, bios, captions, and posts more **unique and eye-catching**.

>*💡 Give your words a fresh look and make every message stand out.*

#### 🤔 Why Choose This Project?

- ✨ **Creative Text Styles** — Turn ordinary text into eye-catching designs with ease.
- ⚡ **Quick & Simple** — Generate stylish text instantly through Telegram.
- 🎨 **Easy to Customize** — Choose the style that best matches your content.
- 🚀 **Easy to Deploy** — Simple configuration makes self-hosting straightforward.

#### 🔄 How It Works

1. 💬 **Send Your Text** — Enter the text you want to style.
2. 🎨 **Choose a Style** — Pick from the available font designs.
3. ✨ **Generate** — The bot instantly converts your text.
4. 📋 **Copy & Use** — Copy your favorite style and use it anywhere.

---

## ✨ Features

- ✨ **40+ Stylish Fonts** — Transform normal text into a wide variety of creative font styles.
- ⚡ **Instant Conversion** — Generate stylish text quickly with a simple Telegram workflow.
- 📋 **One-Tap Copy** — Easily copy your favorite styled text for use anywhere.
- 🎨 **Multiple Text Styles** — Choose different designs to match your messages, bios, captions, and posts.
- 🔤 **Unicode Font Support** — Generate stylish text using Unicode-based characters.
- 📊 **Bot Statistics** — View useful usage and user statistics.
- 📢 **Broadcast System** — Send announcements and updates to bot users.
- 🔐 **Multi Force Subscribe** — Require users to join configured channels before using the bot.
- 🛡️ **User Management** — Ban and unban users directly from the bot.
- 🔧 **Maintenance Mode** — Temporarily disable bot services when needed.
- 📝 **Logging System** — Keep track of important bot activity through the configured log channel.
- 🚀 **Multi-Platform Deployment** — Deploy easily on Koyeb, Heroku, Railway, and other supported platforms.

## 📝 Configuration


| Variable | Description |
|:---------|:------------|
| `API_ID` | Telegram API ID |
| `API_HASH` | Telegram API Hash |
| `BOT_TOKEN` | Bot Token |
| `DB_URI` | MongoDB URI |
| `ADMIN` | Telegram User ID |
| `PICS` | Start Images |
| `IS_FSUB` | Enable / Disable Force Subscribe |
| `FSUB_EXPIRE` | Force Subscribe Expire Time |
| `AUTH_CHANNELS` | Force Subscribe Channels |
| `AUTH_REQ_CHANNELS` | Request FSUB Channels |
| `LOG_CHANNEL` | Log Channel |

## 🤖 Commands

```
start - Check Bot Alive.
stats - Check bot stats.
ban - to ban a user.
unban - to unban a user.
banned - to check banned users.
maintenance - Toggle maintenance mode
broadcast - Broadcast messages to all bot users.
```
